# C FFI Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement `silvestre-ffi` exposing a C-compatible ABI with opaque handles and automated C header generation.

**Architecture:** Wrap `silvestre-core` types behind opaque `SilvestreImageHandle` pointers, safely managing allocations across the FFI boundary, and use `cbindgen` to generate `silvestre.h`.

**Tech Stack:** Rust (`cdylib`, `staticlib`), `cbindgen`, `silvestre-core`

**Spec:** `docs/superpowers/specs/2026-04-29-c-ffi-layer-design.md`

## Global Constraints

- Never panic across the FFI boundary (use `std::panic::catch_unwind` if necessary).
- Thread-safe error tracking using thread-local storage.
