# CLI Tool & Interactive TUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement `silvestre-cli` providing headless filter execution and a full-featured terminal UI powered by `ratatui` with live image rendering.

**Architecture:** Build CLI command hierarchy using `clap`, render RGB half-block pixels in ANSI terminals, and handle reactive keyboard navigation across filter selection and parameter tuning panels.

**Tech Stack:** Rust, `ratatui`, `crossterm`, `clap`, `silvestre-core`

**Spec:** `docs/superpowers/specs/2026-04-29-cli-interactive-tui-design.md`

## Global Constraints

- ANSI terminal compatibility (24-bit true-color where supported, graceful fallback).
- Responsive performance on large images via viewport downsampling.
