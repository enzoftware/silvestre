## 1. Overview

This specification defines the packaging and distribution architecture for `silvestre-wasm` on npm. It allows web developers to install the Silvestre image processing engine via standard package managers (`npm`, `yarn`, `pnpm`) and integrate it seamlessly with modern bundlers (Webpack 5, Vite, Next.js, Rollup) with full TypeScript type definitions.

---

## 2. Package Configuration & Metadata (`silvestre-wasm/Cargo.toml`)

- **Package Name:** `silvestre-wasm`
- **Target Registry:** npm (`https://registry.npmjs.org/`)
- **Metadata:**
  - `license = "MIT"` with local `LICENSE` file packaged in the bundle.
  - `repository = "https://github.com/enzoftware/silvestre"`
  - `homepage = "https://github.com/enzoftware/silvestre"`
  - `keywords = ["image-processing", "wasm", "webassembly", "filters", "rust"]`
  - `categories = ["multimedia::images", "wasm"]`

## 3. Bundler Compilation & Output Architecture

### 3.1 Build Target
- Build command: `wasm-pack build --target bundler --out-dir pkg`
- Generated artifacts:
  - `silvestre_wasm_bg.wasm`: Optimized WebAssembly binary.
  - `silvestre_wasm.js` & `silvestre_wasm_bg.js`: ES module bridge code.
  - `silvestre_wasm.d.ts`: Autogenerated TypeScript type declarations.
  - `package.json`: Normalized npm package manifest.
  - `README.md` & `LICENSE`: Complete documentation and MIT license.

### 3.2 Bundler Compatibility Matrix
- **Vite:** Supported via `vite-plugin-wasm` and `vite-plugin-top-level-await`.
- **Webpack 5:** Supported with `experiments: { asyncWebAssembly: true }`.
- **Next.js:** Supported in both App Router and Pages Router configurations.

## 4. Release Automation (`.github/workflows/release-wasm.yml`)

- **Trigger:** Tag push matching `wasm-v*` or manual `workflow_dispatch`.
- **Pipeline:**
  1. Setup Rust with `wasm32-unknown-unknown` target.
  2. Setup Node.js.
  3. Compile with `wasm-pack build --target bundler`.
  4. Run `npm publish --dry-run` to validate package integrity.
  5. Publish to npm using `NODE_AUTH_TOKEN: ${{ secrets.NPM_TOKEN }}`.
  6. Generate a tagged GitHub Release with automated release notes.

- `wasm-pack build --target bundler --out-dir pkg`: Success with zero errors.
