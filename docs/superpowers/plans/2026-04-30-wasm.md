# WebAssembly Bindings & Web Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement `silvestre-wasm` WebAssembly exports and build an interactive web demo app for client-side browser image processing.

**Architecture:** Bind `silvestre-core` to WebAssembly using `wasm-bindgen`, exposing raw typed array methods that interface cleanly with HTML5 `<canvas>` `ImageData`.

**Tech Stack:** Rust (`wasm32-unknown-unknown`), `wasm-bindgen`, `wasm-pack`, JavaScript, HTML5/CSS

**Spec:** `docs/superpowers/specs/2026-04-30-wasm-web-demo-design.md`

## Global Constraints

- Minimize memory copies when exchanging buffers with JavaScript.
- Clean exception handling converting Rust errors to JavaScript `JsValue` errors.
